# Abstract

This project investigates how an automated medicine delivery system that supports hospital workflows and reduce the cognitive load on overworked medical staff would look as a prototype. In order to address the risks of medication errors and increasing the number of patients, we designed and developed a prototype which consists of a central server and a self-driving deliverance car.  
The server manages order registration, communication and room assignment. While the car autonomously makes the specific route needed and navigates it to the where it afterwards returns to its home base.  
The software implementation functioned reliably and demonstrated that automated route planning, delivery handling, and supervised operation is do able for a hospital delivery robot.  
However hardware limitations became a big issue, particularly the difference between the two motors picked for the prototype, the general size of prototype and the quality of the support wheel. All this prevented the car from performing consistently in the field test scenario.  
Despite this, the project successfully provides a proof of concept and highlights the scalability of the system. The results indicate that with improved hardware and dynamic room configuration, the solution could be expanded into clinically applicable autonomous delivery platform.
