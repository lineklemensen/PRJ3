## Problem formulation
We are then developing a system containing our server and a self driving car. The server gets orders from nurses in a hospital about what medicine needs to be in what room, another nurse will then see the order and fill the car with the medicine needed. Our car then gets a message from the server about what rooms it needs to go to, it calculates how to get there, and when its done it turns on an LED to show it's ready to drive. The nurse can now click a button on the car to start it's route for delivering medicine.
